# 3 分钟全链路演示脚本（V3）

> 对应《阶段 13 任务书》交付标准，基于当前工作台真实界面与演示沙箱按时间轴设计，边操作边口播，全程约 3 分钟。

---

## 演前 1 分钟检查清单

1. **数据库状态**：确认已连接 `knowledge_qa_v3` 并运行过 `go run ./scripts/seed_demo_v2.go`，库内仅向前端暴露 3 个示例项目：
   - `【示例】公共规范库`（`shared`，1 篇 `.md` / 4 段）
   - `【示例】Go/Gin 技术文档`（`go-gin`，39 篇 `.md` / 179 段）
   - `【示例】内容活动运营`（`content-promo`，5 篇 `.docx` + `.xlsx` + `v1 deprecated.md` + `v2 active.md` + `.pdf` / 11 段）
   - 注：阶段 11 盲测夹具 `project-alpha` / `project-beta` 已通过 `is_hidden=1` 隔离，默认首页及日常 `auto` 检索不可见。
2. **启动服务**：
   ```powershell
   # 方式一（全配置直接启动）
   .\start.ps1
   # 或使用阶段 13 一键脚本 / 引导配置模式：
   .\scripts\quickstart.ps1 -SetupUI
   ```
3. **浏览器窗口**：打开 `http://localhost:8080`，确认页面极简干净（无全局静态底边栏；中栏顶部展示口径 B「当前会话」统计栏：`引用准确率：-- · 反馈可用率：-- · 拒答：0 次`）。
4. **准备 1 个更新文件**：桌面或临时目录备好一份修改了内容的 `promo-reward-and-approval-v2.md`（用于现场演示 `overwrite=true` Doc CI/CD 热回归）。

## 分段脚本（00:00 - 03:00）

### 00:00 - 00:30｜开场、痛点引入与即插即用能力（画面：工作台首页 + 顶部引导配置态弹窗）

- **画面操作**：展示清晰的三栏工作台，点一下右上角「模型已就绪」（或展示 Docker / `--setup-ui` 网页引导弹窗），再关闭弹窗回到首页。
- **口播词**：
  > 团队技术文档与运营规范分散在 Markdown、Word、Excel 和 PDF 里，直接把文档丢给通用大模型容易出现幻觉“乱编”、跨项目规则“张冠李戴”，以及更新文档后悄悄破坏原有问答。今天演示的 **Go 知识问答与文档治理工作台（V3）** 用纯 Go + MySQL 8 构建：它既支持一条 `docker compose up` 或 `--setup-ui` 网页免落盘配置模型即插即用，又用严格的评测 Harness 守住每条回答的句级可溯源与拒答底线。

---

### 00:30 - 01:15｜多轮问答、废弃警告、`[n]` 原文 `<mark>` 高亮与任务列表管理（画面：「智能问答」页签）

- **画面操作**：
  1. 保持左侧默认「自动识别（防跨项目串台）」，依次在**同一会话**中连续提问 2 题：
     - 第 1 题：`新版活动发奖规则和端口配置有哪些注意事项？`
     - 等回答渲染完成后，指出 `[1]` `[2]` 引用标签（以及右栏如有老版 v1 切片会标记 `已废弃`），**点击正文 `[1]`**，展示右侧自动高亮滚动并在原文支持句上渲染 `<mark class="evidence-hl">` 荧光背景！
     - 顺手点一下回答下方的 **`👍 准确`**，指出顶部「当前会话」实时变成 `引用准确率：100.0% · 反馈可用率：100.0%`。
     - 第 2 题（同会话续问）：`冬季创作激励活动单篇基础奖励有哪些档位？`（命中 `.docx` 表格切片），展示同一流中垂直新增第 2 轮问答卡片，且左侧「任务」栏自动保存该任务标题。
  2. 鼠标悬停到左侧任务项展示**悬浮详情卡**（完整标题、范围 + 轮数 + 精确时间），点击右侧 `...` 展示仅有的 **置顶 / 重命名 / 删除任务** 三项操作并点击 **置顶**，随后刷新一次浏览器页面展示任务与多轮对话、反馈状态全部从 MySQL 完整恢复。
- **口播词**：
  > 我们在「自动识别」模式下连问两轮内容运营的问题，答案覆盖 Markdown 和 Word 表格。点击答案里的 `[1]`，右侧不仅自动定位原文，还会用纯 DOM `<mark>` 精准高亮支撑这一句话的原句；点下「👍 准确」，顶部「当前会话」统计采用严格客观的“口径 B”，实时根据 `[n]` 校验和真实用户点赞计算准确率，绝不伪造没有真值的虚假 100%。所有任务和历史多轮对话都持久化在 MySQL 中，支持置顶、重命名与管理。

---

### 01:15 - 01:55｜拒答护栏、跨项目歧义拦截与并排对照（画面：「智能问答」页签）

- **画面操作**：
  1. 同会话第 3 题输入语料外问题：`怎么做法式红酒炖牛肉？`
     - 展示系统秒出「文档中没有依据」拒答卡片（Top1 融合分 `< 0.35` 直接拦截，未调 LLM），顶部「当前会话」实时变成 `拒答：1 次`。
  2. 点击 **新对话**，输入跨项目冲突问题：`默认监听端口是多少？`
     - 展示系统弹出**跨项目歧义拦截**黄框，列出命中候选项目（Go/Gin `:8080` 与 内容活动运营 `:8082`），点击 **`全部候选项目并排对照作答`**，直观对比各项目各自独立检索的结果。
- **口播词**：
  > 遇到语料外问题，检索融合分低于 `0.35` 直接零 LLM 拒答，同时自动记入知识盲区雷达；遇到多项目都有“默认监听端口”的冲突问题，系统不猜不混，直接给出候选卡片或并排独立对照，防止跨项目“张冠李戴”。

---

### 01:55 - 02:30｜多格式治理与 Doc CI/CD 覆盖回归（画面：「资料库治理」页签）

- **画面操作**：
  1. 切换到顶部「**资料库治理**」，左侧点选 `【示例】内容活动运营`，展示已入库的 `.docx`、`.xlsx`、`.pdf` 及标注 `已废弃` 的 `v1`（替代链指向 `v2`）。点击一篇 `.pdf` 或 `.docx` 展示右侧全文预览。
  2. 在右侧上传区选择同名文件 `promo-reward-and-approval-v2.md`，勾选 **强制覆盖重切（overwrite）** 点击上传；展开返回的 **Doc CI/CD 局部回归体检单**，展示受该文档影响的回归题自动重跑与黄金切片重绑结果。
- **口播词**：
  > 来到「资料库治理」，Word、Excel、PDF 和 Markdown 都在同一个索引体系下治理，v1 与 v2 版本替代链一目了然。如果我现在勾选「强制覆盖重切」热更新一篇核心规范，后端会自动重绑金标切片并只对受影响的回归题跑一遍 Doc CI/CD 校验，确认无意外拒答或漏答才算安全上线，而且回归跑批不会污染线上知识盲区记录。

---

### 02:30 - 03:00｜盲区反馈闭环与量化基线收尾（画面：「盲区与反馈」页签）

- **画面操作**：
  1. 切换到「**盲区与反馈**」，选中一条待补充盲区（如税务代扣问题）展示「去补充文档」直达入口，再选中刚才点赞的用户反馈展示「加入评测集」转正能力；
  2. 点击左侧 **`运行 feedback 活评测`**，展示 4 道多格式反馈回归题全部绿灯通过，并指向中间滚动列表底部右对齐的 **`全部提问`**（口径 B 全库线上真实提问统计，与离线回归严密隔离）。
- **口播词**：
  > 最后在「盲区与反馈」，线上拒答的问题和用户点踩/好评形成持续运营闭环：缺文档直达补充，有价值的提问转正为 `feedback` 回归题；底部的「全部提问」汇总展示真实线上累计表现，与下方 52 题 `base52`（100% 命中与引用）和 39 题 `holdout` 盲测（近似拒答 13/13 = 100%）严格分层验证，确保每次改动可量化、零退化。演示到此结束！
