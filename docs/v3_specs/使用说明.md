## 核心设计验证重点

1. **盲区隔离、前端 XSS 防护与 Doc CI/CD 验证**：确认 `/api/eval/run` 与 Doc CI/CD 内部回归跑批不会把测试拒答题写入 `knowledge_gaps`；点击 `[n]` 时确认淡黄色 `<mark>` 句级高亮生效，且全文均通过纯 DOM 文本节点渲染、不存在 `innerHTML` 拼接风险；覆盖更新文档后确认 `base52` 与 `holdout` 无退化。
2. **多项目演示语料与零凭据合规**：确认 `corpus_v2/` 演示语料全部采用脱敏业务示例，且仓库代码、脚本与完整 Git 历史中零真实密钥、零本机密码、零私有路径残留。
