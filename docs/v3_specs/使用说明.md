## 推荐新会话开场模板（每阶段一个新会话最稳）

每次打开新会话时，发送以下内容（把 `[X]` 替换成当前要做的阶段，例如 `12_阶段12_盲区雷达与协作闭环.md`）：

```text
请先完整阅读以下文档和当前代码仓库（D:\project\knowledge-qa\v3）：
1. D:\project\knowledge-qa\v3\docs\v3_specs\00_V3总体规格.md
2. D:\project\knowledge-qa\v3\docs\v3_specs\[X]
3. D:\project\knowledge-qa\v3\docs\v2_iterations.md（了解 V2 阶段 11 的 G1/R1 实验结果与红线基线）

前置确认：
- 确认当前处于 feat/v3-harness 分支，禁止修改 master、stage8-delivered、feat/v2-harness 与 stage11-delivered，禁止改动 ..\v1、..\v2 以及原 MySQL knowledge_qa / knowledge_qa_v2 库。
- V3 使用独立 MySQL 数据库 knowledge_qa_v3（通过环境变量或本地未入库的启动脚本，从 ..\secrets\knowledge.txt 获取本地测试凭据，严禁把真实凭据写入仓库追踪文件）。
- 严格遵循任务书范围与《V3总体规格》红线，若遇到技术选型或细节不明确，先向我确认再动手。
- 本阶段全部实现与验收通过后，输出：改动文件列表、运行方式、验收结果（逐项标明是否通过）。
```
