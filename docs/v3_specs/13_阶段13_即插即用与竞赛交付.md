## 任务清单

### 1. 构建“多项目并行团队”演示沙箱语料（`corpus_v2/` + `scripts/seed_demo_v2.go`）
设计一套有真实业务代入感的多项目语料（全部脱敏自编示例，禁止真实公司机密）：
1. **`shared`（团队公共规范域）**：
   - 通用研发与上线值班规范、API 错误码与文档编写约定（`.md`）。
2. **`go-gin`（技术研发项目 A）**：
   - 复用整理后的 Go / Gin 核心文档（含端口默认 `:8080`、中间件、路由组），可复现 V1/V2 基线问答。
3. **`content-promo`（内容消费活动运营项目 B）**：
   - 刻意混用**真实多格式文件**：
     - 1 份 `.docx` 文档：《冬季创作激励活动执行手册》（含 `#`/`##` 标题与活动规则）；
     - 1 份 `.xlsx` 排期表：《活动上线排期与值班预算表》（含多行排期、时间、负责人的表格）；
     - 1 份标记为 `status = deprecated` 的旧文档：《旧版活动发奖与端口配置规范 v1》；
     - 1 份新文档：《新版活动发奖与上线审批规范 v2》（`replaced_by` 指向该文档），**特意包含与 `go-gin` 及其他业务线同名不同值的“服务监听端口/上线审批规则”**，用于直观验证**“跨项目歧义主动澄清”**和**“废弃文档黄色警告”**！
- 编写一键沙箱导入工具 `scripts/seed_demo_v2.go`：幂等创建演示项目、导入多格式演示语料、配置 `deprecated -> replaced_by` 关系、导入演示用的基准/盲测题（绑定 `source_doc_id` 便于现场演示 Doc CI/CD），并可预置 2 条脱敏示例盲区记录供界面展示。

### 2. 即插即用交付包装（满足无环境用户 & Docker 用户）
1. **Docker Compose 一键全栈拉起**：
   - 编写轻量多阶段 `Dockerfile`（Go 编译产物 + 运行时最小镜像，内嵌 `static/index.html`）与 `docker-compose.yml`：
     - `mysql` 服务（MySQL 8，健康检查 + 自动挂载按序执行 `migrations/001_init.sql` 与 `migrations/002_v2_schema.sql`）；
     - `app` 服务（依赖 MySQL 就绪，读取宿主机 `.env` 或传入的环境变量，可选启动参数自动运行 `seed_demo_v2`）。
2. **非 Docker 用户的友好体验（保留标准环境变量契约前提下）**：
   - 提供安全引导选项 `--setup-ui`（默认关闭，不加该参数时 `config.Load()` 严格按总体规格缺变量即退出！）：
     - 当用户显式以 `go run . --setup-ui` 或设置 `ALLOW_WEB_SETUP=true` 启动且尚未填写 `LLM_API_KEY` 等模型变量时，服务仍可起来（仅需 `MYSQL_DSN` 或本地配置），打开 `http://localhost:8080` 弹出简洁的模型配置引导卡片，用户把自己的 `BaseURL / APIKey / Model` 填入内存运行态即可立即体验，**绝不落盘明文写入仓库追踪文件**！
   - 提供干净的通用一键脚本示例 `scripts/quickstart.sh` / `scripts/quickstart.ps1`（不含任何私有路径和 Key，仅检查 MySQL 与环境变量并启动 `seed_demo_v2` + 服务）。
