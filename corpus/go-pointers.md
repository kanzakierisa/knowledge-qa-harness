# Go 指针

## 基本概念

& 取地址，* 解引用。Go 没有指针运算。

```
i := 42
p := &i    // p 是 *int
fmt.Println(*p)  // 42
*p = 21    // 通过指针修改原变量
```

## 零值

指针零值是 nil，解引用 nil 指针会 panic。

## 何时用指针参数

想让函数修改调用方的变量，或结构体较大避免拷贝时，传指针。Go 里所有传参都是值拷贝，传指针只是拷贝了地址。

## new 函数

new(T) 分配一个 T 的零值内存并返回 *T，等价于 &T{}。

## 与 C 的区别

Go 指针安全：不能算术运算，有垃圾回收，返回局部变量的地址是合法的（变量会逃逸到堆上）。
